# Design Research — Reference Sites

Notes on what makes each reference site *not* look AI-generated or templated.
Goal: mine these for techniques, not aesthetics to copy wholesale — the final
design has its own palette/type/signature (see design plan).

## 1. lokkeestudios.com

- Full-bleed **electric violet/purple** hero (no gradient-to-black cliché) —
  commits hard to one saturated color instead of a muted "safe" palette.
- Thin diagonal line "crosshair" decorations radiating from the corners of
  the hero, like lens-flare guide lines — subtle geometric texture instead of
  a stock gradient blob.
- Headline color alternates per-line (white / dimmed-lavender) rather than
  a single flat color — adds rhythm without extra elements.
- Hard, instant cut from bright violet hero straight into a near-black
  section — no fade/gradient transition. The abruptness itself reads as a
  deliberate choice.
- Horizontal-scroll project carousel where each card shows a **giant faded
  ghost-type wordmark** of the project name behind the real (smaller) title —
  typographic depth via scale + opacity, not drop shadows.
- Testimonial cards in a **staggered/cascading vertical offset** (not a neat
  grid) over a dot-starfield background — feels hand-placed, not templated.
- Inline bold on specific words inside quote/body text (not whole sentences)
  to simulate a human editor's emphasis.

## 2. agustinburgos.com

- Near-pure-black canvas with a **lot of dead negative space** — the name
  sits in a small pill/capsule outline with a superscript "™", treating the
  personal brand like a product/trademark. Playful, confident understatement
  instead of a giant hero headline.
- A vertical sidebar ribbon tab on the right edge reading "W. Nominee"
  (awards-style badge presented as a fixed vertical tab, not a footer logo).
- Oversized display word ("ENGINEER") deliberately **cropped/bleeding off
  the top edge** of the viewport — scale used for drama, not readability.
- A row of glowing dots of varying sizes connected by a vertical dotted line
  — a minimal "signal/data" motif, not a generic particle field.
- Two-tone type mixing: a single **italic serif** word ("where") dropped into
  an otherwise all sans/mono page — one deliberate typographic accent.
- Services shown as a two-column spec sheet (bold short label left, flowing
  paragraph right) — editorial/spec-sheet feel instead of icon+card grid.

## 3. riccardozanutta.com

- Page-load **transition wipes** (a colored panel slides/reveals across the
  screen before content settles) — motion as the first impression, not a
  static hero.
- Hard light/dark section break: dark navy hero straight into an off-white
  cream case-studies section — strong contrast used as a section divider
  instead of a subtle background shift.
- Small **hand-drawn-style ink squiggle / scribble icon** next to a section
  label ("Works") plus scattered thin diagonal tick marks as ambient
  decoration — an organic, sketched texture against otherwise clean grids.
- Project captions set in **italic serif** ("Leader in bathroom furniture
  since 1988.") under bold sans titles — editorial magazine caption voice,
  not a tech-stack tag list.
- A dedicated **"Experiments & Open Source" section** ("Web is fun.") listing
  small side-projects/toys numbered 01–04 — separate from formal case
  studies, signals genuine curiosity rather than only client work.

## 4. carlgordonmedia.com

- Gated entry: a black screen with a single notched-corner **"ENTER"**
  button in a monospace/terminal font — a deliberate threshold before the
  site "boots up".
- Background built from a **grid of interlocking rounded-cross/plus shapes**
  with an animated teal→indigo gradient mesh showing through the negative
  space — a custom generative pattern, not a stock mesh-gradient blob.
- Portrait photo framed like an **ID badge/polaroid**: white card mount,
  crosshair reticle icon overlaid on the face, dashed barcode-style line
  beneath — playful "scan this person" conceit.
- Pixel-art glyphs used as UI chrome: tiny pixel running-figure icons, a
  custom icon-strip ("✕ ⊕ >>>>>") — a bespoke iconographic language instead
  of a standard icon font.
- A holographic/iridescent 3D-rendered abstract object (chrome cross shape)
  floating beside the portrait — maximalist Y2K-revival material choice.
- Chunky pixel/blocky display font for the headline with a small "+"
  superscript — ties the type back to the pixel-art motif.

## 5. dvlpr.pro

- Hero uses a literal **isometric 3D illustration of a desk setup**
  (monitor, code editor, coffee mug, keyboard) instead of an abstract shape
  or portrait — concrete, narrative imagery.
- A small **floating gem/crystal** decorative object (isometric, magenta)
  recurs beside the illustration and again lower on the page — a mascot-like
  recurring motif.
- Full-width **ghosted personal photo (just the eyes/face) used as a
  background watermark** behind the About text block — literal personality
  as texture, very bold and unusual.
- About copy explicitly mentions hobbies (boxing, the outdoors, video
  games) — humanizes beyond a tech-stack list.
- A personal-motto pull-quote ("A PROBLEM IS AN OPPORTUNITY TO DO YOUR
  BEST.") used as the section eyebrow before "Skills & Experience" instead
  of a plain label.

## 6. pmportfolio.ca

- Circular monogram badge logo + widely letter-spaced wordmark
  ("P o r t F o L i o") + a bullet-separated tricolon tagline
  ("STRATEGY • UX • GROWTH") — a fully considered "personal logo system"
  rather than plain text branding.
- Hero name rendered with a **per-letter hue gradient sweep** (blue → cyan
  across the individual letters) on a grainy/noise-textured near-black
  background — grain + gradient-per-letter is the signature move.
- Project thumbnails shown as **fanned, tilted 3D-perspective stacks of
  screenshots** (like a spread deck of cards) instead of a single flat
  screenshot — communicates "multiple screens, one project" at a glance.

## 7. chrisabra.co

- Hero background is a **dense wall of repeated role-descriptor phrases**
  ("PROBLEM SOLVER.", "TECH GENERALIST.", "FREELANCE DESIGNER.") tiling
  edge-to-edge at low opacity — identity expressed as typographic wallpaper
  instead of a single tagline.
- A soft blurred multi-color glowing orb (pink/blue/purple) floats over the
  word-wall — one atmospheric light source, not a busy particle system.
- A thin **rainbow gradient bar** recurs as a section-divider/accent line
  across the full width — a small consistent signature detail reused
  site-wide.
- A candid, warm photo (hands forming a heart) instead of a corporate
  headshot — personality over polish.
- Skills shown as **multi-color rotating pill tags** (blue/yellow/orange/pink
  cycling per tag) rather than monochrome badges.

## Cross-cutting takeaways for our design

- **Commit to one bold color move**, don't hedge with a safe neutral palette.
- **A recurring signature motif** beats scattered one-off effects (Chris
  Abra's rainbow bar, dvlpr's gem, pmportfolio's letter-gradient).
- **Editorial/human copy voice** (hobbies, mottos, italic captions) reads as
  authored, not generated.
- **Typographic scale as drama** (oversized/cropped words) is cheap to build
  and very effective.
- **Texture over gradients**: grain, dot-grids, generative patterns, hand-
  drawn marks all read as more "designed" than a smooth mesh-gradient blob.
- Avoid: numbered 01/02/03 step markers unless order is real; generic
  icon-grid "services" sections; centered-everything layouts; a single
  hero gradient blob as the only visual interest.
